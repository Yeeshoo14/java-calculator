# Java Console Calculator

This is a simple console calculator made in Java as part of the Elevate Labs internship Task 1.

## What it can do

* Addition
* Subtraction
* Multiplication
* Division
* Handles division by zero
* Allows multiple calculations
* Gives an option to exit

## Technologies Used

Java and Scanner for taking input from the user.

## How to Run

Compile the program:

```bash
javac Calculator.java
```

Run it:

```bash
java Calculator
```

The program shows a menu, takes the user's choice and two numbers, and then displays the result.
